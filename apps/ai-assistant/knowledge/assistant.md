# ИИ-ассистент

Чат открывается кнопкой «Ассистент» на любой странице приложения после входа. Отдельной страницы чата в меню нет.

Ассистент читает профиль и последние платежи текущего пользователя. Эти данные берутся из сессии на сервере. Идентификатор из текста сообщения не выбирает, чей профиль читать.

Оплату, смену имени и переход по страницам ассистент только предлагает. Пока пользователь не нажал «Подтвердить» или «Отклонить», действие не выполняется. Карту внутри чата провести нельзя.

Внизу поля ввода есть ползунок температуры ответа от 0 до 1. Над ответом показывается короткая строка вызванных инструментов, без сырого JSON.
