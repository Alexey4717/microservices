# Видео

Каталог роликов открывается по адресу `/videos` без входа. Карточка ролика — `/videos/<id>` (UUID), тоже доступна без входа: плеер, название, описание и автор.

Загрузка нового ролика — `/videos/new` только после входа. Анонимный пользователь с каталога попадает на страницу входа, если нажимает «Загрузить видео».

В каталоге только готовые (READY) ролики. Детали конкретного ролика (title, description, url, автор) ассистент берёт из live-данных через инструменты `get_video` / `list_videos` или из снимка «на экране», а не из этой справки.
