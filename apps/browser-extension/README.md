# Учебное расширение Chrome

Пакет `browser-extension` не Nest и не занимает порт. В `start:all` не входит. Кабинет открывайте как `http://localhost:4000`, GraphQL gateway — `http://localhost:3000/graphql`.

Расширение не читает cookie и само не ходит в GraphQL.

Id расширения стабильный: `goonehkbjgmfhkjcbpmjmencjcoghoon`. Его ждёт кнопка на главной кабинета.

## Сборка

Из корня репозитория:

```bash
pnpm run build:extension
```

Chrome загружает каталог `apps/browser-extension/dist` (манифест, service worker, content script, popup и боковая панель).

## Как загрузить

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Укажите `apps/browser-extension/dist`.

После повторной сборки нажмите «Обновить» на карточке расширения. Сочетание клавиш, если Chrome не подставил его само, задаётся на `chrome://extensions/shortcuts`.

## Что смотреть

### 1. Бейдж «новое»

Откройте `http://localhost:4000/videos`. На карточке ролика (`/videos/<id>`, без `/videos/new`) появляется подпись «новое», если этого id ещё нет в `chrome.storage.local` → `seenVideoIds`.

Откройте ролик: id записывается. Вернитесь в каталог — у этой карточки подписи нет. Переходы Next без перезагрузки документа скрипт тоже видит: он следит за `pushState` / `popstate` и заново обновляет DOM. Если подпись не появилась после перехода с другой страницы кабинета, обновите `/videos`.

### 2. Popup

Клик по иконке расширения открывает popup, не панель. На вкладке кабинета виден путь, например `/profile` или `/videos/...`. На другом сайте — «Это не страница кабинета». Кнопка «Открыть панель» открывает боковую панель этой вкладки.

### 3. Боковая панель

На странице ролика (`/videos/<id>`, не `/videos/new`) панель показывает поле заметки. «Сохранить» пишет текст в `chrome.storage.local` → `notes` (id ролика → текст). На других маршрутах панель пишет: «Заметка доступна на странице ролика».

### 4. Контекстное меню и команда

На странице `http://localhost:4000/*` выделите текст и в контекстном меню выберите «Сохранить название». Текст попадает в список `savedTitles` в `chrome.storage.local`. Список виден в инспекторе service worker: Application → Extension storage → Local.

Сочетание `Alt+Shift+K` (команда «Открыть боковую панель») открывает боковую панель. Это пользовательский жест, поэтому `chrome.sidePanel.open` из команды разрешён.

### 5. Напоминание

В popup нажмите «Напомнить про профиль через минуту». Срабатывает `chrome.alarms` с `delayInMinutes: 1`, без `setInterval` в service worker. Примерно через минуту приходит уведомление «Проверьте профиль». Уведомления Chrome должны быть разрешены в системе.

### 6. Счётчик GraphQL

Иконка показывает число запросов браузера на `http://localhost:3000/graphql` с вкладки, адрес которой начинается с `http://localhost:4000`. То же число лежит в `chrome.storage.session` → `graphqlCount`. Тела запросов и заголовок `Authorization` расширение не читает.

Счётчик не видит RSC-запросы и прочие обращения, которые сервер Next делает сам. Такие вызовы идут с Node на `127.0.0.1:3000` и в `chrome.webRequest` не попадают. Поэтому бейдж может быть меньше, чем число строк в логе gateway. Это нормально.

### 7. Сообщение со страницы

На главной кабинета нажмите «Сообщить расширению». Страница вызывает `chrome.runtime.sendMessage` с id расширения. В ответ приходит «Расширение на связи». Если расширения нет и `chrome.runtime` недоступен, кнопка пишет «Расширение не установлено» и не бросает исключение. Входящие внешние сообщения принимаются только с `sender.origin === "http://localhost:4000"`.
